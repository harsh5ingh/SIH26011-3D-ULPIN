# GeoVISTA — Authoritative API Contract

**Platform Name:** GeoVISTA — Geospatial Volumetric Intelligence & Spatial Topology Architecture  
**Problem Statement ID:** PS26011  
**Problem Statement Title:** 3D ULPIN Generation and Vertical Property Mapping System  
**Organization:** Ministry of Rural Development / Department of Land Resources (DoLR)  
**Base URL:** `http://localhost:8000`  
**Swagger UI:** `http://localhost:8000/docs`  
**OpenAPI Specification:** `http://localhost:8000/openapi.json`  

---

## Non-Overclaiming Disclaimer
The identifiers generated by this system are **Proposed 3D Spatial Identifiers — Prototype** (e.g. `IN-MP-BPL-P001-B01-F03-U02`). They represent volumetric spatial candidates and do **not** constitute official Government of India land registration titles or legal ownership certifications. All AI and sensor anomaly detections are spatial candidate assists requiring authorized officer review.

### 5. Officer Geometry Correction (Live State Mutation)
- **Endpoint:** `POST /api/reviews/{id}/correct`
- **Request Body:**
```json
{
  "z_min_m": 514.0,
  "z_max_m": 517.0,
  "footprint_2d": [
    [77.41265, 23.2593],
    [77.4130, 23.2593],
    [77.4130, 23.2600],
    [77.41265, 23.2600],
    [77.41265, 23.2593]
  ],
  "reason": "Officer geometry correction to resolve vertical 3D overlap with Unit 301"
}
```
- **Response 200 OK:** Returns updated `PropertyUnitResponse` with incremented `revision_number`, updated `z_min_m`/`z_max_m`, and automatically re-evaluated `verification_status: "APPROVED"`.
