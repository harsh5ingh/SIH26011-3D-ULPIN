## Core Product Principle
> **"We extend land identity from a flat 2D parcel into an evidence-aware 3D vertical property layer."**

GeoVISTA bridges conventional 2D cadastral records and vertical urban growth by creating unique spatial identities for multi-storey apartments, underground infrastructure, and elevated transit corridors.

### Non-Overclaiming Guarantee
The identifiers generated by this platform are **"Proposed 3D Spatial Identifiers — Prototype"** (e.g., `IN-MP-BPL-P001-B01-F03-U02`). GeoVISTA does not claim to replace legal land title registries or government survey authorities. AI and sensor findings serve as spatial candidate assistants requiring human verification.

## Key Capabilities

1. **Multi-Sensor Spatial Evidence Aggregation:**
   - Drone photogrammetry orthomosaics
   - Aerial LiDAR / 3D point clouds
   - GIS cadastral parcel polygons
   - Architectural CAD floor plans
   - GNSS / CORS reference observations
   - Digital Elevation Models (DEM & DSM)

2. **AI/ML Spatial Pipeline:**
   - Automated building footprint extraction
   - LiDAR vertical floor slice segmentation
   - Vertical parcel volumetric delineation
   - Intelligent topology error detection

3. **Deterministic 9-Rule Spatial Validation Engine:**
   - Real mathematical checking of containment, elevation bounds ($Z_{\text{min}} < Z_{\text{max}}$), horizontal footprint conflicts, vertical 3D overlaps, floor height monotonicity, and cross-sensor discrepancies.

4. **Human-in-the-Loop Officer Workbench:**
   - Review queue, live geometry correction with true backend state mutation, revision history, and immutable audit logs.

5. **Volumetric Cadastre (Underground & Elevated):**
   - Subsurface parking and utility corridors ($Z < 0\text{m}$)
   - Elevated metro transit corridors and air rights ($Z > 12\text{m}$)

6. **Rural Extension:**
   - LiDAR candidate detection on agricultural land
   - Permanence classification (`LIKELY_PERMANENT` vs `LIKELY_TEMPORARY`)
   - False-positive detection (e.g. temporary brick stacks) without unsupported legal claims

## Getting Started

### Prerequisites
- Python 3.11 or newer
- Node.js 18+ and npm

### 1. Start Backend
```cmd
cd backend
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
Swagger API docs: `http://localhost:8000/docs`

### 2. Run Test Suite (Strict 100% Pass)
```cmd
cd backend
python -m pytest tests/test_geovista.py -v
```

### 3. Start Frontend
```cmd
cd frontend
npm install
npm run dev
```
Frontend UI: `http://localhost:5173`

### 4. One-Click Launch (Windows)
Double click `start.bat` in the project root directory.
